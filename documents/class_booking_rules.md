# Class Booking, Cancellation and No-show Rules

Our classes have limited spaces, so Zor Fitness Club uses a booking system to keep things fair.

## How to book
- In the **Zor Fitness app** (Classes tab), or on **WhatsApp 0333-5550967**
- Booking opens **48 hours before** the class starts
- **Elite members** can book **72 hours** ahead. This priority window matters for popular classes like Spin Night and Zumba.
- **Plus and Elite** members book all classes at no charge. **Ladies Only** members book ladies classes at no charge.
- **Standard members and non-members** can book a **drop-in for PKR 1,000**, subject to space
- Student members can only book classes inside their off-peak window, **Mon–Fri 6:00am–4:00pm**

## Class capacity
| Class type | Maximum |
|---|---|
| Spin, Spin Night, Sunday Long Ride (Bahria spin studio) | 24 (one per bike) |
| Zumba (F-7 and Bahria) | 25 |
| All other classes | 15 |

## Waitlist
If a class is full, join the waitlist in the app. If someone cancels, the **first person on the waitlist is booked automatically** and gets a **WhatsApp message**. Once you're auto-booked, the normal cancellation rules apply to you, so remove yourself from the waitlist if your plans change.

## Cancellation: 3 hours' notice
- Cancel at least **3 hours before** the class starts, in the app or on WhatsApp
- Cancelling less than 3 hours before, or not turning up, counts as a **no-show**
- Drop-in fees (PKR 1,000) are **not refunded** for late cancellations or no-shows

## Late arrival: the 10-minute rule
The studio door **closes 10 minutes after the class starts**. This is for safety, because the warm-up has already finished. If you arrive later, you can't join, and it counts as a **no-show**.

## No-show penalty
**3 no-shows in one calendar month = a 7-day class-booking block.** During the block you can still use the gym floor, but you can't book any class. The count resets on the 1st of each month.

## Classes cancelled by the club
- If a class has **fewer than 3 bookings 2 hours before** it starts, it may be cancelled. Booked members get a WhatsApp message.
- If a trainer is ill, a replacement trainer is arranged where possible. Otherwise the class is cancelled and you are notified.
- A class cancelled by the club never counts as a no-show, and drop-in fees are refunded as a credit for another class.

## Health rules for classes
- Members with a **heart condition** need a doctor's note before HIIT Blast or any Spin class
- **Prenatal Yoga** needs a doctor's clearance
- Children aged 13–15 can join supervised group classes with signed parent consent
- **No classes run 1:00pm–2:15pm on Fridays** (Jumu'ah)

## PT is different
Personal training sessions have a **12-hour** cancellation notice, not 3 hours. See the personal training document.
